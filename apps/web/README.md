# @rythmes/web

L'application : la carte du cours, les modules, leurs exemples jouables et leurs
exercices.

**Dépend de :** tous les paquets logiques.

C'est le seul endroit du dépôt qui connaît VexFlow et smplr. Les paquets
logiques produisent des descriptions — ce qu'il faut écrire, quand il faut
sonner — et cette couche les dessine et les joue.
