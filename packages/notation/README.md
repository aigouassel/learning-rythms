# @rythmes/notation

La traduction entre les trois représentations d'un même rythme :
fractions, figures notées, syllabes rythmiques.

**Dépend de :** `@rythmes/core`

Utilisé deux fois — pour afficher un exemple, et pour corriger une dictée.
Il ne connaît pas VexFlow : il produit une description de ce qu'il faut
écrire, pas un dessin.
