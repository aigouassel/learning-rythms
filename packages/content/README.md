# @rythmes/content

Les modules du cours : la prose en MDX, les exercices en données typées.

**Dépend de :** `@rythmes/core`, `@rythmes/notation`

Le compilateur vérifie le contenu. Un QCM a bien une réponse correcte parmi
ses options, une mesure en 6/8 contient bien six croches, aucune leçon
n'emploie un terme introduit plus tard. Une erreur de rédaction devient une
erreur de build.
