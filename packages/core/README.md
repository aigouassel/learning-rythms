# @rythmes/core

Le domaine rythmique : positions en fractions exactes, mesures, motifs.

**Dépend de :** rien

Ce paquet ne dépend de rien et ignore le DOM comme l'audio. La vérité
musicale s'y teste dans Node, en millisecondes. Toute dépendance ajoutée ici
est une régression : c'est l'absence de dépendances qui garantit qu'aucune
importation accidentelle ne puisse passer.
